📘 PRODUCT REQUIREMENTS DOCUMENT (PRD)
Product Title

Academic Roadmaps
Visual, interactive curriculum paths for school students — web-based and lightweight.

Vision

Provide students with clear, structured learning paths for academic subjects (e.g., Math, Physics, Biology). Roadmaps should be visual, interactive, and accessible on all devices, including low-end phones. Admin interface allows curriculum editing without authentication.

🎯 Goals
Primary Goals

✔ Help students navigate school subjects through visual progressions
✔ Allow click-to-open nodes with embedded content and resources
✔ Support nested subnodes (concept hierarchies)
✔ Fast, lightweight, responsive — works anywhere, even offline

Secondary Goals

✔ Admin UI for non-technical editing
✔ No authentication required initially
✔ Easy deployment on Replit, Netlify, Vercel, etc.

🧩 User Personas
Persona	Needs	Primary Use
Student (Primary/Secondary)	Understand subject progression	View roadmaps, read content, explore resources
Admin/You	Populate & edit curriculum	Add/edit nodes, resources, connections

✔ Doesn’t require install
✔ Low memory overhead

Performance Strategies

Lazy-load roadmap library

Code splitting

PWA caching

⚡ Admin Experience

Design Admin API to be:

Predictable schemas

✔ autosave on change
